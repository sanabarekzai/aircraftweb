# ✈️ AircraftWeb — Aircraft Fan Site

A fan-made website for aviation enthusiasts: explore aircraft, browse photos, and learn about legendary planes.

## 🚀 About

AircraftWeb is a fan web project dedicated to aircraft lovers. It showcases:

- ✈️ **Aircraft Gallery** — photos and specs of popular aircraft
- 📖 **Aircraft Encyclopedia** — history and facts about famous planes
- 🔍 **Search & Filter** — find aircraft by name, category, or manufacturer
- 💬 **Fan Corner** — a place for fans to share their favorite aircraft

## 🛠️ Built With

- HTML5 / CSS3
- JavaScript

## 📦 Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/sanabarekzai/aircraftweb.git
   ```
2. Open `index.html` in your browser.
